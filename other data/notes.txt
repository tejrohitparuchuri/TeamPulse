    What is a React Router DOM?

        React Router DOM is a library that helps you to create multiple pages inside a single-page react app
        It helps you to navigate:
          /home
          /login
          /signup
          /dashboard
          without refreshing the browser
    
    Why do we need React Router?

        React normally shows only oe component at a time.
        If you want:
          Home Page
          About Page
          Login Page
          Contact Page
        You need a way to switch betwn components based on the urlReact Router does exactly that

    ⭐ Basic Concept on components:
     
        There are 3 main components:

            1. BrowserRouter
                wraps the entire app
                It enables routing
            2. Routes
                A wrapper for qall your Route components
            3. Route
                Define which component should show for a specific URL
            4. Install CMD
                npm install react-router-dom

    Spring IoC (Invension of Control) is a core concept in the Spring Framework that changes how objects are created and managed in a program.
        
        Simple Idea
        
            Instead of your code creating and managing objects, the spring container does it for you.
    
        Spring IoC = letting Spring create and manage your objects instead of doing it manually.
            
            IoC is implemented using Dependency Injection (DI), where dependencies are provided to objects instead of being created inside them.

        What is Dependency Injection?

            Dependency Injection (DI) is a technique where :
                
                an object gets the required Dependency from outside instead of creating it itself

            Dependency Injection is the process of providing an object's dependencies from an externaal container (Spring IoC container) rather than creatingthem inside the class.
            This reduces tight coupling and increases flexibility

            Types of Dependency Injection in Java & Spring :

                There are mainly 3 types of Dependency Injection :
                1. Constructor Injection
                2. Setter Injection
                3. Field Injection

JPA Mappings (@OneToMany, @ManyToOne, @OneToOne, @ManyToMany), DTO Mapping, Pagination, Sorting

    What are JPA Mappings?
        JPA Mapping means connecting Java Object/classes with database tables and connecting relationships between those tables
        
        In simple words:
            JPA tells java how your classes are related to each other and how those relationships should be stored in the database.
            JPA: Java Persistence API
            Hibernate is the most commomly used implementation of JPA in Spring Boot.

    @OneToOne: one row here matches exactly one row there (eg: a Student has exactly one ID card)
    @OneToMany/@ManyToOne: a pair used together. One parent row has many child rows, each child points back to its parent (eg: A department has many studnets)
    @ManyToMany: Many rows on each side connect to many rows on the other, needing a join table (eg: students enroll many courses, each course is enrolled by many studnets)
